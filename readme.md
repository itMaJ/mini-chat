# mini-chat

一个基于 Go 的简易聊天室项目，第一阶段围绕用户认证、聊天室管理和实时聊天搭建基础功能。

> 当前处于初始化阶段，以下功能均为开发计划，尚未实现。

## 第一阶段功能

| 功能 | 具体描述 | 优先级 |
| --- | --- | --- |
| 用户注册与登录 | 支持注册、登录，使用 JWT 进行身份认证 | 必须 |
| 聊天室管理 | 创建、加入、退出聊天室 | 必须 |
| 实时消息 | 通过 WebSocket 实时发送和接收消息 | 必须 |
| 消息持久化 | 使用 MySQL 保存历史聊天记录 | 必须 |
| 历史消息查询 | 分页加载聊天记录 | 必须 |
| 在线状态 | 显示用户在线、离线状态 | 必须 |
| 私聊功能 | 用户之间一对一聊天 | 推荐 |
| 群聊功能 | 多用户群组聊天 | 推荐 |

## 技术选型

- Go：后端服务，当前 `go.mod` 声明版本为 1.21.1。
- WebSocket：客户端与服务端实时通信。
- MySQL：存储用户、聊天室及聊天记录。
- JWT：用户身份认证。

## 开发顺序

1. 完成用户注册、登录和 JWT 认证。
2. 实现聊天室创建、加入与退出。
3. 接入 WebSocket，实现聊天室消息收发。
4. 接入 MySQL，实现消息保存与历史记录分页查询。
5. 实现用户在线、离线状态展示。
6. 按需补充私聊与群组聊天。

## 运行说明

目前尚无可运行的服务入口，启动方式及数据库配置将在对应功能完成后补充。
